## Parent

[Specification #1](https://github.com/AedenBryce/Interactive-HV-Network/issues/1)

## What to build

Explore one connected whole-network model, review the accumulated discrepancies step by step and establish the owner-approved starting configuration and model version.

Implement this as a complete model/session/UI/test slice using the approved simulation-session boundary in the parent specification. Synthetic fixtures must be explicitly identified. Real-network interpretations require source evidence or owner confirmation; unresolved facts remain labelled unconfirmed. Successful software tests do not constitute model acceptance.

## Acceptance criteria

- [ ] Combine all area models using stable identities and reconciled cross-area connection/interface records, without inventing connections to force the graph together.
- [ ] Account for every supplied PDF in the coverage register: reviewed in-scope content, explicit duplicate/reference relationship or a documented disposition. Intake counts alone are not coverage acceptance.
- [ ] Verify complete agreed network coverage through final LV buses, retaining any scope/boundary issue requiring the owner's decision; exclude outgoing LV circuits.
- [ ] Present the accumulated discrepancies with drawing evidence and affected assets for the owner's step-by-step confirmation, and record each resolution instead of choosing drawing precedence silently.
- [ ] Review the whole diagram, asset connections, source availability, supported device states, interlock rules and starting configuration with the owner.
- [ ] Resolve acceptance-blocking ambiguities or obtain an explicit owner decision on their model boundary/treatment; never silently declare an unconfirmed installed arrangement correct.
- [ ] Record explicit owner model acceptance and the starting configuration against an immutable model version. Preparing the package or passing software tests does not close this acceptance criterion.
- [ ] Demonstrate cross-area impact/path scenarios and run structural/evidence-based regression checks against the assembled model.
