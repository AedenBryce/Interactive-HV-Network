## Parent

[Specification #1](https://github.com/AedenBryce/Interactive-HV-Network/issues/1)

## What to build

Launch the local V1 with the accepted whole-network model and use switching, impacts, navigation, history and versioned scenario files without requiring the PDFs.

Implement this as a complete model/session/UI/test slice using the approved simulation-session boundary in the parent specification. Synthetic fixtures must be explicitly identified. Real-network interpretations require source evidence or owner confirmation; unresolved facts remain labelled unconfirmed. Successful software tests do not constitute model acceptance.

## Acceptance criteria

- [ ] Provide reproducible local startup/use instructions and package the accepted whole-network model with its agreed starting configuration.
- [ ] Demonstrate overview/detail navigation, asset/source actions, independent source/earth connectivity, interlock blocks, impact explanations, tracing, undo and reset on the integrated application.
- [ ] Save and reopen a matching-version real-model scenario; open a deliberately different-version snapshot in view-only mode with electrical mutations prevented.
- [ ] Show that startup and scenario exploration work without the source PDFs or a separate historical model file.
- [ ] Complete the approved meaningful session tests and targeted browser checks for the delivered behaviour; record any remaining limitation explicitly instead of treating unconfirmed physical facts as verified.
- [ ] Confirm V1 still covers the entire accepted network through final LV bus endpoints and includes the recorded owner model acceptance.
- [ ] Keep production GPT Site deployment, electrical calculations, live equipment integration and a network editor outside this deliverable.
