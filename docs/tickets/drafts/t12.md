## What to build

Inspect the station switchboards, generator/source branches and 33 kV line in the application with unresolved external connections explicitly marked.

Scope: Station SB01/SB02 and 33 kV overhead line.

Implement this as a complete model/session/UI/test slice using the approved simulation-session boundary in the parent specification. Synthetic fixtures must be explicitly identified. Real-network interpretations require source evidence or owner confirmation; unresolved facts remain labelled unconfirmed. Successful software tests do not constitute model acceptance.

## Acceptance criteria

- [ ] Visually review the supplied station and 33 kV line SLDs; model evidenced bus/coupler, generator/source, transformer, line switching and endpoint/interface relationships with source references.
- [ ] Record named cross-area interfaces for the main switchroom and Hopper 10 without inventing missing supply paths.
- [ ] Reconcile station/legacy overview references where evidence allows; retain unresolved external and future-feed arrangements as review records.
- [ ] A drawn generator, outgoing connection or future feed does not automatically become a confirmed available source or an accepted starting state.
- [ ] Render the station/line views with working supported state controls, source availability and path inspection; disable affected unresolved interlock controls.
- [ ] Validate the model and add session-level regressions for evidenced relationships/provisional status. No source beyond the supplied coverage is silently declared disconnected.
