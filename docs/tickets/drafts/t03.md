[Specification #1](https://github.com/AedenBryce/Interactive-HV-Network/issues/1)

## What to build

Operate earth switches in a synthetic network and independently inspect source connectivity, earth connectivity and conflicts.

Implement this as a complete model/session/UI/test slice using the approved simulation-session boundary in the parent specification. Synthetic fixtures must be explicitly identified. Real-network interpretations require source evidence or owner confirmation; unresolved facts remain labelled unconfirmed. Successful software tests do not constitute model acceptance.

## Acceptance criteria

- [ ] The model and session represent earth terminations and the fixture's supported earth-switch states explicitly.
- [ ] Users inspect source and earth connectivity independently, with explanatory text as well as visual indications.
- [ ] A modelled enabled-source-to-earth path is highlighted as a source-to-earth conflict; the indication alone does not create an undocumented switching prohibition.
- [ ] Separate circuits with earth connections are not connected to one another through a shared-earth through path, and earth is not treated as an electrical source.
- [ ] Session tests and a browser check demonstrate earthing an otherwise source-disconnected section and the fixture's source-to-earth conflict.
