## What to build

Open a scenario from a different model version using its saved original network, inspect it and trace paths while all electrical mutations remain disabled.

Implement this as a complete model/session/UI/test slice using the approved simulation-session boundary in the parent specification. Synthetic fixtures must be explicitly identified. Real-network interpretations require source evidence or owner confirmation; unresolved facts remain labelled unconfirmed. Successful software tests do not constitute model acceptance.

## Acceptance criteria

- [ ] Compare the saved scenario model version with the current model version; a mismatch uses the saved original snapshot rather than remapping states onto the current model.
- [ ] Clearly identify the viewed scenario's model version, the current version and view-only mode.
- [ ] Pan, zoom, selection, asset inspection and existing path tracing remain usable.
- [ ] Switching, source changes, undo and reset are disabled by the session interface as well as by visible controls; viewing a historical scenario does not overwrite the current model.
- [ ] Tests cover matching-version exploration, a mismatched snapshot with changed topology/identities and direct attempts to bypass view-only controls.
